# Island

A Dynamic-Island-style widget for Windows: your day plan, study blocks, gym, water, music player with live lyrics,
volume/brightness, timers, notifications, desktop widgets and a phone remote, all in one pill at the top of the screen.

## Install
1. Install Python 3.12+ from python.org (tick **Add python.exe to PATH**).
2. Put this folder somewhere permanent and outside OneDrive, e.g. `C:\island`.
3. Double-click `setup.bat`.

## Fastest way: let your AI do it
Tell Claude Code (or any AI that can run commands on your PC):

> Clone https://github.com/Aboodkiller/island into C:\island, read AI_SETUP.md and set it up for me.

## Make it yours
Open your AI (Claude Code, Claude Desktop with file access, etc.) **in this folder** and say:

> Read AI_SETUP.md and set up Island for me.

It will ask about your classes, study plan, gym, meals and apps and fill everything in. The plan files that ship
here are only examples, and the study plan starts empty.
